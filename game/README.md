# 借风群岛 · Windseed Isles

修船厂等着用的泵体到了。车尾和车头各能分担多少？你指挥吊机把货放上车，司机要等前后两根轴都过磅才拉走。下一辆车有两件货，其中一只工具箱丢了铭牌。

## 进港试玩

**从仓库运行**。在 Godot 4.7.2 的项目管理器中导入 `game/project.godot`，等素材导入完成，按 **F5**。游戏使用 GDScript，仓库已附上可用的模型、港口地图和离线手册。[项目文件](project.godot)

**从 Windows x64 试玩包运行**。把整个 ZIP 解压到同一目录，保留相邻的 `Windseed.exe` 和 `Windseed.pck`，双击 `Windseed.exe`。下方的构建命令可以从仓库生成这份 ZIP。

启动后选「给第一辆车配载」。用鼠标把箱子从栈台拖到车板上的刻度，或用空格起吊、A / D 选落点、空格落箱。刻度从后轴起算，往车头增大。按 1 / 2 选货，E 读吊秤，G 过磅。手柄用 A 起落、左摇杆或十字键移落点、RB 换箱、X 读秤、菜单键过磅。

第一辆车停在便携轮秤上，每次松钩后都能读两轴的重量。要事先算好货位，按 **F / LB** 打开配载尺，选这件货分给前轴的重量，把换算出的箱心位置划到车板。第二辆在装货区只能看空车磅单，得把车开上出口地磅才能读到新的轴荷。超限可以带着原车回来调货。过磅次数、起吊次数和实测值都会记上磅票，J 可翻看并比较。车辆静止在水平面上时，前轴新增载荷乘轴距等于各箱重量乘其到后轴的水平距离之和。[刚体转动与角动量](../01-经典力学/05.html)

| 在哪里 | 玩家决定什么 | 可以从哪里查证 |
| --- | --- | --- |
| 货车配载 | 称无铭牌的箱子，给不同轴距的车布置货位 | 看轮秤，核对实际轴荷与限载，比较移箱前后的磅票 |
| 货运岸桥 | 选何时收速，何时起落吊箱，怎样把回程货吊过船边 | 回看本吊小车与箱心的位置、速度和第一次落板 |
| 五板雾琴 | 换敲击节奏召船，同一声港钟能否承受一块板加重 | 冻结合成振动中占主导的一阶，逐板比较弹簧合力与质量乘加速度 |
| 双灯塔 | 改应答牌，给第四艘船押一个结果，再转动读头，签下一批船的实测回执 | 两塔各有本地灯志，合表才见到关联。可以换成全白噪声或扩大样本重试 |
| 测风邮船 | 留下或投出唯一的浮标，系缆候风、走裂帆峡或绕灯笼湾 | 比较预测的多条航迹和船实际偏移，再换十倍精度的探头重走同一场雾 |

配载泊位的「岸桥驾驶」可自由操作小车和吊索，把船上的机件放上平板车，再把补给装回较高的船面。A / D 移动，W / S 收放吊索。落稳后可以回看刚才停车时小车与箱子的轨迹。港口地图另有「工棚试摆台」，可摘挂横簧，自由实验两个摆怎样交换能量。按 **Tab / Y** 随时翻到此处对应的仓库课件，合上书就接着玩。按 **J / 手柄查看键** 打开航海日志，选一条记录可与本站上一次尝试并排看。五板雾琴、双灯塔和测风邮船各拿到一份回执后，码头会装好三份相关的航测匣，供你带上布翼艇。

## 驾驶布翼艇

在主港选「开始新的远航」，选一件改装，放飞。A、D 转向，W 拉升，S 俯冲。按住空格收翼抢速度，松开展翼。穿过第一道门便有了进港所需的风种。下一岛会起侧风，同一航线和航测匣可以重飞，跟自己的最佳航迹比一场。

| 操作 | 键盘 | 手柄 |
| --- | --- | --- |
| 转向、拉升和俯冲 | A D、W S 或方向键 | 左摇杆或十字键 |
| 收翼 | 按住空格 | 按住 RT 或 A |
| 打出测距浮标 | E | X |
| 切换读头或查看航测匣签 | Q | LB |
| 查随船手册 | Tab | Y |
| 暂停 | Esc | 菜单键 |

## 在航线上学物理

- **驾驶本身**。俯冲把高度换成空速，转弯会增加阻力，热柱把整团空气向上托。改装会改变诱导阻力、寄生阻力或翼载。结算图用同一长度单位画出高度与空速折合高度，能看出哪次拉升花掉了最多速度。
- **沿途的双灯标**。晴礁湾可以转动检偏器寻找浮种。风琴峡以读头的共振响应辨认信号。暮金群岛用两组有限的模拟测量记录比较经典相关与量子相关。错过灯标仍可带着普通风种完成航段。
- **344 张航测匣**。在主港或机库选择一节课或一项研究。一张匣提供四组有条件、有单位的模型读数。前三站亮出紫环，第四站藏起货物，你根据输入条件与先前三次观察，驾驶到预期刻度。结算会显示模型值、实际飞过的位置和收货结果。可以把四次记录导出为 CSV。
- **随船手册**。可搜索仓库 319 节正文和 25 项研究训练的模型、推导或实施要求。飞行中打开手册会暂停，默认显示刚刚经历的现象与已装载的课题。研究航测提供原项目中的一个可玩的模型片段，完整复现仍有原项目列出的实验、分析与交付要求。

航测值来自各匣签说明的教学模型。飞行采用简化阻力极线、配平、失速与风场模型。速度、高度、时间和盲接位置取自本次实际飞行。进度、获救云鳐与最佳航迹保存在 Windows 的 `%APPDATA%\WindseedIsles`。导出航测后可在结算页直接打开数据目录。

## 无窗口测试

在仓库根目录运行以下命令。示例使用 Python 3.10+，假定 Godot 4.7.2 编辑器在 PATH 上，命令名为 `godot`。首次从干净副本测试时，先导入素材。

```powershell
godot --headless --audio-driver Dummy --editor --path game --import
python game/tools/check_play.py
```

测试脚本为每组场景创建临时存档，以 Godot 的 `--headless --audio-driver Dummy` 模式运行。模拟输入只发给测试进程。要单测货车配载，加 `--only loading`。其他分组是 `quay`（岸桥驾驶）、`harbor`（港口委托）和 `voyage`（飞行与航测）。若编辑器使用其他文件名，在导入命令中使用它的实际路径，并用 `--godot` 将同一路径传给 Python 脚本。[游戏回归脚本](tools/check_play.py)

## 构建 Windows 试玩包

安装与编辑器版本匹配的 Windows x86_64 导出模板，再从仓库根目录运行下面两条命令。也可以用 `--template` 给导出脚本指定本机的 release 模板。

```powershell
python game/tools/export_windows.py --archive game/build/Windseed-Windows-x64.zip
python game/tools/check_play.py --pack game/build/windows/Windseed.pck
```

第一条命令在 `game/build/windows/` 生成程序和数据包，并将两者打入 `game/build/Windseed-Windows-x64.zip`。第二条命令用实际导出的数据包重跑游戏回归。构建和录制文件保存在本地的 `game/build/`。[Windows 导出脚本](tools/export_windows.py)

## 课程与素材维护

修改中文课程后，从仓库根目录运行 `python game/library/build_library.py`，同步提交生成的 `game/library/course_library.json`。游戏直接读取这份目录。各航测匣的数据按领域编号维护。[手册构建脚本](library/build_library.py) · [航测数据 00–08](survey/cases_00_08.tsv) · [09–16](survey/cases_09_16.tsv) · [17–25](survey/cases_17_25.tsv)

港口地图和航线模型附有 Blender 后台生成脚本。修改几何或配色时，可用 Blender 5.1 重建对应素材，并同步提交更新后的贴图、模型或地图坐标。[港口地图脚本](art/source/build_harbor.py) · [航线模型脚本](art/source/build_models.py)

Windows 试玩版可离线运行。Steam 商店页、应用编号、商店构建提交和审核属于后续发行工作。
